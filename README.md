# Athlete on Tour

The season engine for individual-sport athletes — discover events worldwide, build a smart race calendar, and plan travel, peaks and logistics in one place.

**Domain:** [athlete-on-tour.com](https://athlete-on-tour.com)

## What it is

Team-sport athletes get leagues and fixtures handed to them. Solo athletes (cyclists, runners, triathletes, chess players, climbers, …) hunt across dozens of federation sites, forums and PDFs. Athlete on Tour pulls it into one feed and turns it into a planned season.

- **Discover** — every relevant event ranked by fit, distance and date
- **Schedule** — A/B/C race priorities with auto build / peak / taper blocks
- **Tour** — registration deadlines, travel, lodging and start-list intel per event
